# Kindle 自動キャプチャ（Windows）

Kindle の閲覧画面を自動でページ送りしながら、各画面をキャプチャして JPEG 画像として連番保存し、検索可能なPDFまで作るツールです。追加ソフトは不要です。

高速版では長い固定待ちを使わず、ページの変化、描画の停止、文字輪郭の鋭さを約45ミリ秒間隔で検知します。低解像度の仮表示から高解像度表示へ切り替わったことを待ってキャプチャし、JPEGは再圧縮せずPDFへ直接格納します。

Version 2.4.2では配布物を `KindleCapture.exe` 1ファイルに統合しました。内部スクリプトはEXEに内蔵され、CMD・VBS・PS1を並べる必要はありません。ドラッグ不要のカーソル自動範囲指定、保存先指定、160×120の画面特徴量・輪郭強度によるぼやけ防止、透明OCR、PDF再作成をすべて同じGUIから利用できます。範囲指定の成功をエラー扱いするWindows PowerShell 5.1固有の終了コード取得問題も修正しています。成功時はダイアログを表示せず、GUI内の「指定済み」表示だけを更新します。

## ダウンロード

リポジトリ内の `KindleCapture.zip` をダウンロードして展開し、`KindleCapture.exe` を起動してください。Windows全体の実行ポリシーを変更する必要はありません。

## ソースからビルド

Windows 10または11のWindows PowerShellで、リポジトリのフォルダーから次を実行します。追加のビルドツールは不要です。

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

同じフォルダーに `KindleCapture.exe` と `KindleCapture.zip` が生成されます。

## 使い方

1. Kindle for PC で対象の本を開き、キャプチャを始めるページに移動します。ページ送り方向を自動判定する場合は、最初のページから始めてください。
2. Kindle のページ中央をクリックし、ツールバーやメニューを閉じます。
3. `KindleCapture.exe` をダブルクリックして設定画面を開きます。CMD画面は表示されません。
4. 「対象ウィンドウ」で、本文を表示しているKindleを選びます。Kindleは一覧の先頭へ優先表示されます。
5. 「保存先」にフォルダーを直接入力するか、「参照…」から選択します。存在しないフォルダーを入力した場合は開始時に作成します。
6. 保存ページ数を指定します。`0`にすると、同じ画面が続いて最終ページと判定するまでキャプチャします。既定値は`1500`枚です。
7. ページ送り方向、キャプチャ範囲、速度モードを選びます。
   - 方向 `Auto`：左右の矢印をテストして自動判定（既定）
   - キャプチャ範囲 `カーソル自動指定`：カーソル位置からKindle本文の画面境界を自動検出（既定・推奨）
   - キャプチャ範囲 `ウィンドウ全体`：Kindleのクライアント領域全体を使用
   - 速度 `Turbo`：最速、`Balanced`：描画が遅いPC向け、`Safe`：長いアニメーション向け
8. `カーソル自動指定`の場合は「画面部分を自動指定」を押します。Kindle本文へカーソルを移動すると、その位置を含む大きな画面部品が緑枠で自動選択されるので、枠が本文に合った状態で1回クリックします。ドラッグや座標調整は不要です。選択した相対領域は全ページに自動適用され、ウィンドウの移動・拡大縮小にも追従します。`Esc`でキャンセルできます。
9. 「ぼやけ防止待ち」を設定します。既定値はTurbo=`350`、Balanced=`550`、Safe=`900`ミリ秒です。`0`で輪郭確認を無効化できます。
10. 必要に応じてOCR、最大待ち、重複停止回数、類似判定を調整します。
11. 「キャプチャ開始」を押します。範囲をまだ指定していない場合は、ここでカーソル自動指定画面が開きます。
12. 自動方向判定後、3秒のカウントダウンを経てキャプチャが始まります。以後はマウスやキーボードに触れず待ちます。進捗は設定画面下部のログに表示されます。

選択した保存先の中に、実行ごとの `captures_年月日_時分秒` フォルダーを作成します。同じ秒に開始した場合も末尾番号を付けて分離します。連番JPEGに加えて、全ページをまとめたA4サイズのPDFも自動生成し、完了後にそのフォルダーを開きます。既定の保存先は「ドキュメント\KindleCapture」です。OCRを有効にすると、画像の見た目を変えずに検索・選択・コピーできる透明テキスト層が付きます。

EXEは内蔵スクリプトを `%LOCALAPPDATA%\KindleCapture\2.4.2` に展開して実行します。Windows 全体の実行ポリシーやレジストリは変更しません。

## 停止方法

- `F12` を押すと中止します。
- GUIの「停止」ボタンでも安全に中止できます。強制終了せず、キャプチャ済みJPEGからPDF作成へ進みます。
- PDF/OCR作成中に`F12`を押した場合も中止できます。キャプチャ済みJPEGは残ります。
- ほぼ同じ画面が3回続くと、最終ページと判断して自動停止します。微小な描画差があっても判定できます。
- `1`以上の任意枚数を指定した場合は、重複を除いた実際の保存枚数がその値に達すると停止します。`0`なら枚数では停止しません。

キャプチャ中はWindowsの自動スリープを一時的に抑止し、終了時に元へ戻します。開始前には、JPEG画像と最終PDFの両方を含めて1ページ約2MBとして空き容量も確認します。

## 高速化の調整

- まず`Turbo`と高解像度待ち`350`ミリ秒で試してください。従来のような固定2秒待ちはありません。
- 文字がぼやけて保存される場合は、最大待ち時間ではなく高解像度待ちを先に`500`～`800`ミリ秒へ増やします。
- ページアニメーション自体が途中で保存される場合は`Balanced`、さらに残る場合は`Safe`を選びます。
- ページ変化を検出できない場合だけ、最大待ち時間を`3000`～`5000`ミリ秒へ増やします。
- コマンドラインからは `-OutputRoot "D:\KindlePDF" -SpeedMode Turbo -RenderSettleMilliseconds 500 -DelayMilliseconds 1500 -OcrMode On -OcrLanguage ja` のように指定できます。

## ページ送り直後のぼやけ対策

Kindleがページ送り直後に低解像度の仮表示を出す場合、画面の動きが止まっただけではキャプチャを開始しません。短時間の高解像度待ちを置いたうえで、160×120サンプルのラプラシアン輪郭強度が上昇し終わり、連続して安定したことを確認します。自然に文字が少ないページでも絶対値では判定せず、そのページ内での変化が止まったかを使います。

処理中には `clarity ... ms, sharpness ...` が表示されます。ぼやけが残る本では高解像度待ちを増やし、十分きれいなら小さくすると速度を戻せます。

## PDF・透明OCRテキスト

既定ではWindows標準の日本語OCRを使用し、PDF作成時に各ページの文字と座標を透明テキストとして埋め込みます。日本語の単語間に不要な空白が入りにくいよう調整しています。OCRはキャプチャ後に実行されるため、ページキャプチャ速度には影響しませんが、PDFの完成までにはページ数に応じた追加時間がかかります。

日本語OCR言語がWindowsに入っていない場合は警告を表示し、画像だけのPDFを残します。OCRを使わずPDF作成を最速にしたい場合は、質問で`N`を選ぶか `-OcrMode Off` を指定してください。

## 途中失敗からPDFを再構築

各キャプチャフォルダには `capture-session.json` が作られ、設定、保存枚数、処理状態、エラー内容が記録されます。エラー時には詳細な `capture-error.txt` も可能な限り残します。

キャプチャ済みJPEGからPDFだけを作り直す場合は、GUIの「画像からPDF再作成」を押し、`page_*.jpg` が入った `captures_年月日_時分秒` フォルダーを選択します。OCR設定はGUIの現在値を使用します。

`page_2.jpg`と`page_10.jpg`のように桁数が異なる名前でも、ページ番号を数値として並べます。JPEG、進捗JSON、PDFはいずれも一時ファイルへ完全生成してから確定するため、途中で失敗しても不完全なファイルを正常な成果物として扱いにくい構成です。既存PDFを作り直す場合も、正常な旧PDFを残したまま置き換えます。

## 誤キャプチャ防止

- 選択したウィンドウのハンドルだけでなくプロセスIDも毎回確認します。
- Kindleを前面化できない場合は、CMDや別アプリをキャプチャせず停止します。
- 本文をクリックする前にも対象ウィンドウを照合し、Windowsがクリックや矢印キーを送れなかった場合は停止します。
- 選択範囲はKindleクライアント領域内の比率で保持するため、ウィンドウを移動・拡大縮小しても追従します。
- Per-Monitor V2 DPIに対応し、拡大率が異なる複数モニターでも座標ずれを抑えます。
- 最初の画像の明るさとコントラストを検査し、真っ白・真っ黒・ほぼ単色なら警告します。

## 注意事項

- 実行前に、手動で左右の矢印キーを押して正しいページ送り方向を確認してください。
- キャプチャ対象はウィンドウ一覧から明示的に選択します。Kindleを検出できない場合も、CMD画面を自動選択することはありません。
- ウィンドウタイトルだけでなく、実際のKindleプロセスを優先して候補にします。
- 自動方向判定はページを一度送って元に戻すため、必ず最初のページで実行してください。うまく判定できない場合は`R`または`L`を手動指定します。
- 画像が重複・欠落する場合は、速度モードを`Balanced`または`Safe`へ変更してください。
- キャプチャ中に別のウィンドウを操作すると、安全のため停止することがあります。キャプチャ中はPCを操作しないでください。
- 購入済み書籍を自分で利用する範囲に限定し、作成した画像やPDFを第三者に共有・配布しないでください。
